# Devlogs de Topin de Zombies

Un informe por avance importante, pensado para publicar en redes (Instagram, TikTok) y
mostrar el progreso a quien quiera apoyar el proyecto.

| Devlog | Fecha | Lo principal |
|---|---|---|
| [#1](2026-10-26_devlog_01/README.md) | 26 oct 2026 | Campaña de 20 noches, 4 jefes, estilo PS1, mejoras visibles, controles |

## Qué trae cada devlog

```
devlog/AAAA-MM-DD_devlog_NN/
├─ README.md     informe + textos listos para copiar y pegar
├─ reels/        videos verticales 1080×1920 (sin audio, para poner un sonido en tendencia)
├─ carrusel/     imágenes 1080×1350 para Instagram, numeradas en orden
└─ capturas/     capturas sueltas del juego
```

Los clips se graban con `herramientas/devlog/` (un jugador automático y el Movie Maker de Godot).
